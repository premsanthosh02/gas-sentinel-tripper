# Gas Sentinel Tripper

Gas Sentinel Tripper is a safety system designed to detect LPG gas leakage and automatically trip the MCB to prevent fire hazards.

## Features
- LPG gas leakage detection
- Automatic MCB tripping system
- Real-time safety response

## Objective
To prevent accidents caused by gas leakage using automation.

## Components Used
- Gas Sensor (MQ series)
- Microcontroller
- Relay Module

## Status
Prototype completed
