# Gas Sentinel Tripper 🚨

Gas Sentinel Tripper is a smart safety system designed to detect LPG gas leakage and automatically trip the MCB to prevent fire hazards.

## 🔥 Key Features
- LPG gas leakage detection
- Automatic MCB tripping mechanism
- Real-time safety response
- Reliable and fast hazard prevention

## 🎯 Objective
To enhance safety in homes and industries by preventing gas-related accidents using automation and electrical protection systems.

## ⚙️ Components Used
- Gas Sensor (MQ series)
- Microcontroller (8051 / Arduino / Raspberry Pi Pico)
- Relay Module
- Power Supply Circuit

## ⚡ Working Principle
When gas leakage exceeds a safe threshold, the sensor detects it and sends a signal to the controller. The controller activates a relay, which trips the MCB and cuts off electrical power to prevent fire hazards.
